# week-2-project-B084
Footprinting, Reconnaissance and Scanning

Project Overview
This project doucuments my week 2 practical experience during the Cybersecurity and Ethical hacking at Networkwalks.

The project focused on footprinting, reconnaissance, Open-Source Intelligence (OSINT), and network scanning using Kali Linux and Windows.

Tools used included WHOIS, Nslookup, WhatWeb, cURL, Wafw00f, DNSRecon, theHarvester, Nmap, and Zenmap.

Through these exercises, I gained practical experience in gathering domain information, identifying web technologies, enumerating DNS records, discovering live network hosts, and generating network topology maps.

All activities were conducted within authorised testing environments for educational purposes.

Key Learning Outcomes:

* Understanding passive and active reconnaissance.
* Performing OSINT using theHarvester.
* Identifying network hosts using Nmap and Zenmap.
* Analysing DNS records and HTTP response headers.
* Identifying potential security risks and recommending improvements.
